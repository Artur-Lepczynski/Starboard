# Starboard

Private personal project: a React + TypeScript app (Vite) that displays NASA and other free space APIs in an exciting way.

## Code style

- Always end statements with semicolons (`;`) in TypeScript/JavaScript files.
- Use kebab-case for CSS class names (e.g. `apod-card`), never camelCase.
- Do not add comments to generated code. The only exception is a comment that is vital for readability and understanding, such as a non-obvious reason or a surprising behavior the code cannot show on its own.
- Place a comment before the language structure it describes, never inside it. For example, comment on interface fields above the interface, not between its fields.

## Git commits

- Never add a `Co-Authored-By: Claude` line (or any Claude attribution) to commit messages.
- Prefix every commit message with a keyword and a colon, e.g. `feat:`, `fix:`, `chore:`, `docs:`, `refactor:`, `test:`, `style:`, `perf:`.
